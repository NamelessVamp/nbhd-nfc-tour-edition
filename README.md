# THE NBHD NFC Tour Edition

Sitio estatico de una sola pagina para 5 experiencias NFC.

## Probar localmente

Abre `index.html` con doble clic. Prueba estas variantes:

- `index.html?house=love`
- `index.html?house=void`
- `index.html?house=oblivion`
- `index.html?house=chrome`
- `index.html?house=signal`

## Publicar en GitHub Pages

1. Crea un repositorio publico, por ejemplo `nbhd-nfc-tour-edition`.
2. Sube `index.html` a la raiz.
3. Abre Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Selecciona `main` y `/ (root)`, luego Save.
6. Usa la URL que GitHub Pages indique y agrega `?house=...`.

## Distribucion recomendada para 20 etiquetas

- LOVE: 5
- VOID: 5
- OBLIVION: 4
- CHROME: 3
- SIGNAL: 3

## Antes de grabar

Prueba cada URL en Android y iPhone. Visiona la pagina completa y usa el boton Spotify. No bloquees las etiquetas NFC hasta terminar todas las pruebas.

## Aviso

Proyecto fan-made no oficial. Conserva el aviso del footer. Las portadas se cargan desde URLs externas, por lo que necesitan internet.
